# Yandex DC: Anti-Terrorist & Drone Defense (ЗРПК «Панцирь-С1»)

Интерактивная игра-симулятор защиты дата-центра Яндекса от БПЛА на **FastAPI / Python** + правила антитеррористической безопасности ЦОД.

## Возможности игры:
- **Оружие и прокачка:**
  - На старте: оборонный пулемёт + взрывной импульс РЭБ (`E`).
  - После 20 сбитых дронов: разблокировка ракетного комплекса **ЗРПК «Панцирь-С1»** (спаренные 30-мм автопушки 2А38М + самонаводящиеся ракеты ЗУР с осколочно-фугасным подрывом на `F` / `ПКМ`).
- **Сложность:**
  - Динамическое нарастание скорости и интенсивности налёта с каждым сбитым дроном.
- **Управление:**
  - Стрельба: `ПРОБЕЛ` / `ЛКМ`
  - Ракеты (Панцирь-С1): `F` / `ПКМ`
  - Импульс РЭБ (мгновенный подрыв дронов): `E`
  - Наведение: `←` `→` / `A` `D` / Мышь
- **Правила безопасности:**
  - Прокрутка страницы колёсиком мыши вниз открывает подробные антитеррористические рубежи безопасности дата-центра Яндекса.

## Запуск:
```bash
pip install fastapi uvicorn
python main.py
```
Открыть в браузере: `http://localhost:2222`

## Материалы:
В папке `end/` сохранены инфографики с антитеррористическими рубежами ЦОД (формат 2:3).
